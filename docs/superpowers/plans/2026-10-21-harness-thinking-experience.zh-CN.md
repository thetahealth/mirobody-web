# 前端 Harness 思考体验：实现与验证记录

[English](2026-10-21-harness-thinking-experience.md)

> 本文记录 2026-10-21 的前端适配。用户已授权前端配合后端 harness 调整，并在后续要求提交 PR。保留现有界面风格及四种前端语言。

**目标：** 尽早展示真实进展，将思考、工具执行与最终答案分开，并准确处理停止接收和超长对话的状态。

**架构：** 沿用现有类型化流事件、思考面板和 60 ms 批量更新机制。首个非空思考或答案块，以及影响执行状态的事件，立即送到界面。所有流内容和结束回调绑定问题 ID，通过请求 Promise 统一处理完成与中止。后端通过 LangGraph 自定义流发送不含摘要正文的 `context` 事件，反映真实的摘要生成过程。

**技术栈：** React 19、Zustand、Vite、Vitest；后端为 Python 与 deepagents。

## 范围与约束

- 前端基线为 `2d6891f`，已与 `origin/main` 核对。
- 支持英文 `en`、简体中文 `zh-CN`、繁体中文 `zh-TW`、日文 `ja`。本次没有增加依赖或实现语音功能。
- 等待提示属于界面状态，不算模型 token。首个非空 `reasoning` 或 `text` 才计为首个可见 token。
- 上下文整理事件只携带操作 ID、阶段和状态，不包含摘要正文或健康数据值。
- 摘要生成完成不代表摘要已提交到上下文，也不代表记忆质量已经通过验证。评测仍以 `usage.context` 中的执行记录为依据。
- 保留用户主动展开、折叠和滚动的位置。复制只包含最终答案，并且只有剪贴板写入成功后才显示“已复制”。
- 浏览器验证使用合成数据及独立本地服务。部署是单独的操作，不属于本次 PR。

- 前端共 **34 个测试文件、460 项测试通过**。Lint 零错误，保留未修改的 VisChart、ProviderList、UploadFiles、Login 代码中的四个已有警告。

- 初次前后端联合验证中，后端 21 个公开及本次新增测试模块共 **754 passed、107 skipped、12 xfailed**。Ruff、编译、六条依赖边界规则、裸库导入和 diff 检查通过。完整 `pytest` 仍有相同的五个既有、被 gitignore 排除的测试收集错误。
- 浏览器验证实际走过 HTTP SSE 解析器、状态存储和渲染组件，覆盖：首段 thinking 先于最终答案、两个并行工具、成功但内容为空的工具结果、部分结果、上下文整理状态、停止后立即重问、历史回放不显示运行时钟、复制成功与被拒绝、Enter/Space 展开折叠、四种语言、减少动画，以及 390 px 视口和多模型对比卡片无横向溢出。

- 生产构建已同步到后端 `../mirobody/frontend/`；**74 个文件的 SHA-256 完全一致**，目标目录没有多余资源。尚未部署。
- 临时浏览器验证页面已从源码目录移除。本机复核所需的临时脚本保存在 `/private/tmp/mirobody-web-harness-qa.html`、`/private/tmp/mirobody-web-harness-qa.jsx` 和 `/private/tmp/mirobody-harness-sse-qa.py`。这些路径是本机临时材料，不是仓库依赖。

## 尚未完成的验证与能力边界

- **停止接收不等于取消服务端计算。** 后端目前会在客户端断线后继续生成并保存答案。前端中止 HTTP 请求后，不再接收该轮结果；后续刷新历史可能看到后台保存的完整答案。真正取消生成的能力已登记在后端 roadmap。
- **尚无真实模型的 100 题新评分或硬件 TTFT 新测量。** 本次验证覆盖代码契约与交互行为，不据此宣称模型性能或硬件首 token 延迟已经提升。
- 服务端摘要事件来自真实执行；浏览器测试使用合成 SSE。两者分别验证了事件产生和界面消费，不能替代真实模型在线端到端评测。
